# הוראות התחלה לצוות

התיקייה הזאת (`team_kit/`) נמצאת בענף נפרד בשם `team-kit` ולא ב-`main`, והענף יימחק לפני ההגשה. אל תמזגו אותו ל-`main`. בתוכה:

- `CLAUDE.md`: ההקשר המשותף של הפרויקט וכללי העבודה, ל-Claude Code של כל אחד.
- `PART_1.md`, `PART_2.md`, `PART_3.md`: החלק האישי של כל סטודנט (משימות, תלויות, מה לספק לאחרים, מה נחשב טוב).

## מי מחזיק מה

בלוח יש עמוד נפרד לכל אחד (שחר, טל, אוהד, לפי סדר החלקים, אפשר לשנות שמות בלשונית המשימות) ועמוד אחד להחלטות המשותפות. כל אחד מחליט בעמוד שלו, והמשותפות מחליטים ביחד. בעמוד של כל אחד יש כפתור "העתק את ההחלטות שלי ל־Claude", שמעתיק סיכום מוכן להדבקה.

| חלק | משימות | נקודות בערך |
|---|---|---|
| חלק 1 | סביבה, Q1 א׳ (מודלים), Q1 ג׳ (אימות), Q1 סיכום, Q2 ה׳ (דוח) | 36 |
| חלק 2 | Q1 ב׳ (ניתוח), Q1 ד׳ (מימושים), Q2 א׳ (ביקורת נתונים), Q2 ב׳ (ניקוי) | 32 |
| חלק 3 | Q2 ג׳ (שאלות), Q2 ד׳ (חריגים), איחוד והגשה | 35 |

אפשר לשנות את החלוקה בלוח המשימות (לשונית "משימות וחלוקת עבודה"). אם משנים, מעדכנים גם את הקובץ של החלק.

## התחלה, צעד אחר צעד

1. **הרשאות.** מי שמנהל את המאגר מוסיף אתכם כ-collaborators ב-GitHub, ומשתף איתכם את לוח ההחלטות בהרשאת עריכה.
2. **שכפול המאגר:**
   ```bash
   git clone https://github.com/Talpeleggg/Mini_Project_1.git
   cd Mini_Project_1
   ```
3. **הבאת הקבצים.** הקבצים בענף `team-kit`. מוציאים אותם בלי להכניס אותם ל-git שלכם:
   ```bash
   git fetch origin team-kit
   git archive origin/team-kit team_kit | tar -x
   ```
   אחר כך מעתיקים לשורש המאגר את `CLAUDE.md` ואת הקובץ של החלק שלכם בשם `MY_PART.md` (למשל `PART_2.md` ← `MY_PART.md`). הקבצים האלה לא יעלו בטעות, כי ה-`.gitignore` מעלה רק קבצי הגשה.
4. **סביבה:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
5. **ענף אישי:**
   ```bash
   git checkout -b p2-analysis
   ```
6. **פתיחת Claude Code בתיקיית המאגר**, והודעה ראשונה כזו:

   > קרא את CLAUDE.md ואת MY_PART.md. סכם לי את החלק שלי במשפטים קצרים בעברית, ותגיד לי אילו החלטות מהלוח עדיין חסרות. אל תכתוב קוד לפני שבחרתי את ההחלטות של המשימה.

7. **עבודה:** מחליטים בעמוד האישי שלכם בלוח (ובעמוד המשותף יחד), לוחצים "העתק את ההחלטות שלי ל־Claude" ומדביקים ל-Claude, מסמנים סטטוס בלוח המשימות, ומבקשים ממנו לכתוב קוד של משימה אחת בכל פעם.
8. **לפני commit:** מנקים פלט מהמחברות (הפקודה ב-`CLAUDE.md`), ופותחים Pull Request שסטודנט אחר מאשר.

## חשוב

- **ההחלטות הן שלכם.** Claude לא בוחר במקומכם. אם הוא לא רואה את הלוח, מדביקים לו את "סיכום החלטות".
- **כל אחד חייב להבין את כל הקוד שמוגש.** בהערכה יכולים לבקש מכל אחד להסביר או לשנות כל חלק.
- **סעיף 9 ב-`AI_USAGE.md`** (דוגמה שערערתם עליה) חייב להיות אמיתי ושלכם.
- **אבני דרך:** 18.11 החלטות וחוזי ממשק, 25.11 טיוטות, 28.11 איחוד וסקירה צולבת, 1.12 הרצה מאפס, 2.12 מרווח ביטחון, 3.12 הגשה.
