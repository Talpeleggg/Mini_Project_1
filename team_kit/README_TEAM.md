# הוראות התחלה לצוות

התיקייה הזאת (`team_kit/`) נמצאת בענף נפרד בשם `team-kit` ולא ב-`main`, והענף יימחק לפני ההגשה. אל תמזגו אותו ל-`main`. בתוכה:

- `CLAUDE.md`: ההקשר המשותף וכללי העבודה, ל-Claude Code של כל אחד.
- `PART_1.md`, `PART_2.md`, `PART_3.md`: החלק האישי של כל סטודנט (משימות, תלויות, מה לספק לאחרים, הקבצים שלו, מה נחשב טוב).

## מי מחזיק מה

בלוח יש עמוד נפרד לכל אחד (שחר, טל, אוהד, לפי סדר החלקים, אפשר לשנות שמות בלשונית המשימות) ועמוד אחד להחלטות המשותפות. כל אחד מחליט בעמוד שלו, והמשותפות מחליטים ביחד. בעמוד של כל אחד יש כפתור "העתק את ההחלטות שלי ל־Claude", שמעתיק סיכום מוכן להדבקה.

|---|---|---|
| חלק 1 | סביבה, Q1 א׳ (מודלים), Q1 ג׳ (אימות), Q1 סיכום, Q2 ה׳ (דוח) | 36 |
| חלק 2 | Q1 ב׳ (ניתוח), Q1 ד׳ (מימושים), Q2 א׳ (ביקורת נתונים), Q2 ב׳ (ניקוי) | 32 |

## איך עובדים ב-git

- **כולם דוחפים ישירות ל-`main`.** אין סוקר ואין Pull Request.
- **כל אחד עובד רק על הקבצים שלו.** שתי המחברות הסופיות משותפות, ולכן בזמן העבודה הן מפוצלות זמנית לקבצים נפרדים בתיקייה `parts/` שכבר קיימת ב-`main`. המפה המלאה ב-`parts/README.md`.
- **בלי קונפליקטים:** כשאף אחד לא נוגע בקובץ של אחר, אין מה להתנגש. לפני כל push מריצים `git pull --rebase`.
- **קבצים משותפים לא נוגעים בהם בזמן העבודה:** `README.md`, `AI_USAGE.md`, `requirements.txt` והמחברות הסופיות. כל אחד מתעד את השימוש שלו ב-AI בקובץ `parts/ai_log_part<מספר>.md`. אם צריך חבילה חדשה, מודיעים לקבוצה ומוסיפים שורה אחת ל-`requirements.txt` אחרי `git pull --rebase`.

## התחלה, צעד אחר צעד

1. **הרשאות.** מי שמנהל את המאגר מוסיף אתכם כ-collaborators ב-GitHub, ומשתף איתכם את לוח ההחלטות בהרשאת עריכה.
2. **שכפול המאגר:**
   ```bash
   git clone https://github.com/Talpeleggg/Mini_Project_1.git
   cd Mini_Project_1
   ```
3. **הבאת הקבצים.** הקבצים בענף `team-kit`. מוציאים אותם בלי להכניס אותם ל-git שלכם:
   ```bash
   git fetch origin team-kit
   git archive origin/team-kit team_kit | tar -x
   ```
   אחר כך מעתיקים לשורש המאגר את `CLAUDE.md` ואת הקובץ של החלק שלכם בשם `MY_PART.md` (למשל `PART_2.md` ← `MY_PART.md`). הקבצים האלה לא יעלו בטעות, כי ה-`.gitignore` מעלה רק קבצי הגשה.
4. **סביבה:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
5. **פתיחת Claude Code בתיקיית המאגר**, והודעה ראשונה כזו:

   > קרא את CLAUDE.md ואת MY_PART.md. סכם לי את החלק שלי במשפטים קצרים בעברית, ותגיד לי אילו החלטות מהלוח עדיין חסרות. אל תכתוב קוד לפני שבחרתי את ההחלטות של המשימה.

6. **עבודה:** מחליטים בעמוד האישי שלכם בלוח (ובעמוד המשותף יחד), לוחצים "העתק את ההחלטות שלי ל־Claude" ומדביקים ל-Claude, מסמנים סטטוס בלוח המשימות, ומבקשים ממנו לכתוב קוד של משימה אחת בכל פעם בקבצים שלכם ב-`parts/`.
7. **לפני כל push:**
   ```bash
   jupyter nbconvert --clear-output --inplace parts/<שם המחברת>.ipynb
   git pull --rebase
   git add parts/<הקבצים שלכם>
   git commit -m "הודעה קצרה"
   git push
   ```
